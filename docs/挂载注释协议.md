# 节点与连线的挂载注释

Flow Coding 使用原生 draw.io 子便签保存注释，客户端默认隐藏正文，在所属节点或连线上显示注释角标（数字为注释数）。点击角标在程序内打开置顶悬浮卡，可拖动标题栏调整位置，不遮罩或阻止画布操作；卡片打开时，选中其他节点或连线直接切换到其注释，无注释时显示空状态。可编辑、添加、删除或解除挂载；切换目标或关闭卡片时保存正在编辑的正文，点「取消」放弃本次编辑。右键普通便签选择「挂载到节点或连线…」，再点击目标；Esc 取消挂载。右键节点/连线可直接添加注释。

## Agent 改图规则

- 属于某个业务节点的说明挂到该节点；属于转移、条件或时序的说明挂到对应连线。简短分支条件仍用连线标签。
- 全图约束可保留独立 note 并集中摆放，不按距离猜测归属，不把跨多个环节的说明随意绑到一个节点。
- 注释用 `shape=note;fcNote=1;`，`vertex="1"`；`parent` 必须是同页内已存在的业务节点或连线 ID，几何必须 `relative="1"`。
- 保存完整正文、原 note ID、尺寸及已有属性，HTML 正文按 XML 属性规则转义。保留 `shape=note`，避免计入业务节点与 Feat 状态统计。
- 不使用 `visible="0"`，不把正文只放在 tooltip 或本机存储中。正文的收起属于客户端显示策略；在其他 draw.io 编辑器中仍保留可见的原生便签。
- note 不作为主流程节点参与自动布局，不用业务连线表达注释归属。已有说明连接线不直接删除，确认语义后处理。
- 默认不挂到另一个 note、不建立循环父子关系；每条注释只有一个宿主，一个宿主可以有多条注释。
- 复制、拆图或更改 ID 时保持 note 的 parent 引用正确；删除宿主会连同其附属注释删除，需要保留时先解除挂载。复制宿主时，子 note 随之复制并使用新 ID。
- 保持已有图坐标，除非用户授权重新布局。布局后检查宿主和连线、注释 parent 与相对几何；不把已挂载 note 重新平铺到图层根部。
- 修改前后沿用项目 `flowctl lock` / `flowctl unlock` 规则，验证同页 ID 唯一、parent 存在、无循环、正文未丢失。现有未标记的独立 note 不自动转换。

## 节点注释示例

宿主 `n3` 已存在。note 的 x/y 为宿主宽高的相对比例，offset 为附加偏移；以下偏移供原生 draw.io 显示正文时使用，Flow Coding 角标固定在节点右下侧，与 ID / Feat 角标错开。

```xml
<mxCell id="note3" value="安全边界&lt;br&gt;执行前重新检查授权。"
  style="shape=note;fcNote=1;whiteSpace=wrap;html=1;align=left;spacing=8;fillColor=#fff2cc;"
  vertex="1" parent="n3">
  <mxGeometry x="1" y="0" width="300" height="120" relative="1" as="geometry">
    <mxPoint x="16" y="24" as="offset"/>
  </mxGeometry>
</mxCell>
```

## 连线注释示例

宿主 `e2b` 已存在。x 在 -1（起点）到 1（终点）之间，0 表示沿折线总长度的中点；y 是垂直于线段的偏移。默认 y=24，与原有连线标签错开。Flow Coding 使用第一条注释的 x/y 定位汇总角标；多条注释在同一个入口查看。

```xml
<mxCell id="note4" value="重复投递不重复判断、不重复推理。"
  style="shape=note;fcNote=1;whiteSpace=wrap;html=1;align=left;spacing=8;fillColor=#fff2cc;"
  vertex="1" parent="e2b">
  <mxGeometry x="0" y="24" width="300" height="120" relative="1" as="geometry">
    <mxPoint x="0" y="0" as="offset"/>
  </mxGeometry>
</mxCell>
```

`fcNote` 为 Flow Coding 扩展样式字段；普通 draw.io 不依赖它读取 note 正文及父子关系。Flow Coding 的图片/PDF 导出默认只表达当前可见主流程，展开正文需在原生 draw.io 中导出；注释全文始终保存在图文件内。
