# Fix_261105_3 操作提示区域定位

> 状态：已关闭
> 应用：flow_coding
> 创建：2026-11-05　　关闭：2026-11-05

## 1. 现象
### 1.1 问题描述
用户要求 Feat 复制反馈显示在 Feat 提示区域，流程图复制反馈显示在流程图提示区域。原先两侧共用全窗口提示，按整个页面居中。

### 1.2 复现步骤
1. 在同一 APP 并排打开流程图和 Feat。
2. 分别复制档案路径、流程图路径或引用。
3. 观察提示的区域归属及水平中心。

### 1.3 影响范围
流程图和 Feat 的复制、保存及错误反馈；分栏、独立窗口和流程图全屏布局。

## 2. 根因分析
- 2026-11-05 追踪复制回调、saveState 与 Feat setState：两侧都进入同一个 floating-status。
- 2026-11-05 检查 CSS：原提示使用固定定位 left: 50%，中心取整个窗口，缺少内容区域锚点。

**根因**：两个内容区共用窗口级提示容器与计时器，无法分别定位和独立显示。
**确信度**：已定位到根本原因。

## 3. 修复方案
- app.js / feat.js：分别转入 flow、feat 提示入口，按区域维护计时器；关闭内容时清理对应提示。
- index.html / style.css：各内容区增加原生 popover，使用 CSS anchor 按自身区域底部居中，只读标识显示时向上避让 8px。
- 路径复制成功与失败均进入本区域提示；保持鼠标穿透、半透明和六秒自动收起。
- 流程图：仅调整界面反馈定位，业务逻辑架构不变，无需改图。
- 结果：用户于 2026-11-05 指示先提交，再重新编译启动。
