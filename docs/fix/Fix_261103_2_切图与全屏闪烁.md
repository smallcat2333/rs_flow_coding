# Fix_261103_2 切图与全屏闪烁

> 状态：已关闭
> 应用：flow_coding
> 创建：2026-11-03　　关闭：2026-11-04

## 1. 现象

### 1.1 问题描述

用户反馈此前切图闪烁修复仍未生效，进入和退出全屏也会闪烁。最终缩放与中心坐标正确不代表过渡过程正确，需要检查实际绘制帧。

### 1.2 复现步骤

1. 打开一张流程图，调整位置和缩放，再切换到另一张图或已有页签。
2. 按 F11 进入全屏，再按 F11 或 Esc 退出；在全屏中平移、缩放后重复退出。
3. 检查过渡过程是否出现纯色空帧、旧图位置或中间布局。

### 1.3 影响范围

主窗口和独立流程图窗口的切图、全屏切换；保留缩略导航、最新浏览位置及现有只读规则。

## 2. 根因分析

- 已检查 ui 及其上级至 E: 的 CodeGraph 索引，均不存在，使用源码复核调用链。
- 当前切图遮罩为纯色；fc-render-ready 使用 setTimeout(0) 与同步图验证，不等于已呈现到屏幕。
- 全屏先改变原生窗口、外层布局，再向 iframe 发消息，尚无绘制完成回执。具体影响待逐帧复现验证。
- 本仓库未发现相关业务流程图；本次只排查绘制实现，不额外补图。

- 独立 Chromium、1280×800 / 1600×1000，使用原有 mock 样例；仅在测试中加入 120ms 读图延迟与 45ms 原生窗口回执延迟，模拟真实异步 I/O 和窗口改尺寸。
- 基线逐帧：切图 26 帧中 25 帧为纯色遮罩；进入全屏中心由 `(351.5, 292.5)` 先变成 `(511.5, 392.5)`，之后恢复；退出中心由 `(352, 293)` 先变成 `(192, 193)`，之后恢复，布局后续仍有尺寸变化。
- 页签切换的 Flow / Feat 打开与关闭也会在图加载消息之后继续调整布局；仅检查最后一次坐标漏掉了中间帧。

- 2026-11-04：用户反馈切回 `飞书消息接入与问答流程.drawio` 后一直显示“正在载入流程图”。原文件 28,587 字节、70 个单元，XML 与应用同源解析器均通过；原生 WebView2 直接打开也正常，排除文件损坏。
- 2026-11-04：原生 WebView2 在 2000×1100 视口稳定复现“纯 Feat 页签 → 原图＋原 Feat 页签”：6 秒后 `st.loaded=true`、`flowNavigating=false`、`tabChanging=false`，但 `#editor-wrap` 仍有 `loading`。图先载完时，`fc-render-ready` 因 `tabChanging` 暂缓揭图；两栏完成后的 `tabApi.end()` 只检查 `frozen`，而此前关闭流程图后没有冻结层，因此永久漏掉最终揭图回执。

**根因**：原生窗口、外层布局和 iframe 视图分批更新，缺少完整绘制事务；切图的纯色遮罩本身形成空帧，全屏又没有冻结旧画面及完成绘制回执。后续页签事务还漏掉了“图先载完、无冻结层”的收尾分支。
**确信度**：已定位到根本原因；源码、受控逐帧复现与原生 WebView2 页签切换证据一致。

## 3. 修复方案

- `ui/flow_bridge.js`：改变图或窗口布局前克隆当前画布与缩略图，形成鼠标穿透的冻结层；最终画布尺寸、缩放、平移与滚动连续两帧稳定，并再完成一轮绘制后，通知外层解除冻结。
- `ui/flow_bridge.js`：进出全屏先记录最新画布中心与缩放；画布后续变尺寸时继续恢复该视图，用户开始平移、缩放或定位节点后释放旧中心约束。
- `ui/app.js`：切图先冻结再读文件；全屏先等待冻结回执，再改变窗口与布局，最后等待绘制回执。读取失败和关闭流程图时清理冻结状态。
- `ui/tabs.js`、`ui/app.js`：图和 Feat 两栏的打开、关闭作为同一次绘制事务，等栏布局完成再展示新图。
- 2026-11-04：`ui/app.js` 的 `tabApi.end()` 补齐 `st.loaded` 判断；即使没有冻结层，只要图已先于 Feat 加载完成，也重新确认最终绘制，随后解除载入遮罩。图尚未载完时继续等待真实载入回执，不伪造完成状态。
- `ui/style.css`：已有冻结画面时不再显示纯色载入遮罩；首次打开仍保留载入提示。
- 追加检查定位到冻结层自身的位移：全屏冻结层提前铺满 iframe，旧图横移 5px、上移 13px。改为始终跟随实际画布边界；相同视口下复测冻结前后位置和尺寸差均为 0。
- 流程图：无。本次只调整绘制时序，不改变业务逻辑架构。
- 保留用户及其他会话对相同文件的共同编辑；本次未追加 README 记录、未暂存或提交。
