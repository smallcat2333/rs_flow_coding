# Fix_261102_1 独立窗口白屏卡死

> 状态：已关闭（用户授权统一提交）
> 应用：rs_flow_coding
> 创建：2026-11-02　　关闭：2026-11-03

## 1. 现象
### 1.1 问题描述
用户反馈 0.2.2 弹出 Feat 独立窗口后白屏，关闭无效。截图中原生窗口已创建，但页面没有加载。

### 1.2 复现步骤
1. 运行 Windows release 版 0.2.2，打开任意 Feat。
2. 点击右上角弹出按钮。
3. 弹出窗口白屏，点击关闭无效。

### 1.3 影响范围
Windows 下流程图和 Feat 独立窗口创建、以及创建后应用的 IPC 和关闭操作。

## 2. 根因分析
- 2026-11-02：核对正在运行进程的两个原生窗口，确认白屏弹窗与主窗口属于同一进程。
- 检查 `open_popout` 调用链，发现同步 Tauri 命令直接调用 `WebviewWindowBuilder::build`。
- 已安装 Tauri 2.12.5 的 `src/webview/webview_window.rs` 第 58 行明确说明 Windows 下该用法会死锁，并提供 async command 示例。
**根因**：同步 IPC 命令内创建 WebView2 窗口，触发 Windows 事件循环死锁。
**确信度**：已定位到根本原因（同步命令与 Tauri 官方已知问题吻合，改为异步后真实 release 的 Feat 弹出已验证正常显示）。

## 3. 修复方案
- `src-tauri/src/lib.rs`：仅把 `open_popout` 改为异步命令，让 Tauri 在异步运行时处理窗口创建；补充 Windows 线程约束注释。
- 按用户追加要求，`ui/app.js` 支持独立窗口 Esc 关闭，`ui/flow_bridge.js` 转发 iframe 内的 Esc；draw.io 对话框优先处理 Esc。
- 不调整文件存储和窗口路由。
