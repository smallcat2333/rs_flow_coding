# Fix_261102_3 节点选中误打开档案

> 状态：已关闭（用户要求停止后续验证并提交）
> 应用：rs_flow_coding
> 创建：2026-11-02　　关闭：2026-11-02

## 1. 现象
### 1.1 问题描述
用户期望普通点击流程图节点只更新选中状态，点击节点右上角书签标签才打开关联 Feat；当前普通选中也会打开档案或弹出多 Feat 列表。来源：用户，2026-11-02。

### 1.2 复现步骤
1. 打开含 Feat 标签的流程图。
2. 关闭 Feat 栏，点击已挂 Feat 的节点主体。
3. 观察 Feat 栏或档案选择框是否自动打开。

### 1.3 影响范围
主窗口和独立流程图窗口中的节点选择、书签点击及多 Feat 选择。

## 2. 根因分析
- 2026-11-02 代码走查：普通选中与书签点击均发送 `fc-select`；`onNodeSelect` 对非程序定位直接路由 Feat。
**根因**：节点选中通知同时承担打开档案的职责，无法区分节点主体点击与书签点击。
**确信度**：已定位到根本原因。

## 3. 修复方案
- 将书签打开请求与节点选中通知分开；节点选中只更新状态和跨窗口广播，书签点击单独触发档案路由。
- 保留多 Feat 选择、缺失档案提示、程序定位、挂接/摘除与跨窗口路由。
- 本仓库 docs/flow 无对应模块现状图；本次按明确的点击行为调整范围直接走查现有桥接调用链。
