# Fix_261103_1 侧栏选中高亮粘连

> 状态：已验证待确认
> 应用：rs_flow_coding
> 创建：2026-11-03　　关闭：-

## 1. 现象
### 1.1 问题描述
用户于 2026-11-03 提报：点击侧栏条目时，之前另一类条目仍显示相同蓝色高亮，看起来选中项粘连。

### 1.2 复现步骤
1. 打开任一 Chart。
2. 打开任一 Feat。
3. 观察 Chart 和 Feat 同时保留蓝色选中背景。

### 1.3 影响范围
侧栏分层及平铺列表的 Chart / Feat 选中反馈。

## 2. 根因分析
- 2026-11-03 源码走查：app.js 的 openDiagram 仅切换 `.file.active`；applyFeat 仅切换 `.feat.active`。Sidebar.rowClass 又分别按 currentFlow / currentFeat 重建 active。
- 2026-11-03 本地预览复现：打开 `/mock/flow/chat.drawio` 后打开 `/mock/feat/Feat_261101_1_查询缓存.md`，DOM 中同时存在两个 active 条目，计算背景色均为 rgb(28, 53, 87)。
- 当前项目 docs/flow 不存在；本次仅诊断实现层的选中反馈，不新建业务流程图。

**根因**：Chart 和 Feat 独立维护当前打开项，却共用 active 选中样式；没有统一的侧栏选中项。
**确信度**：已定位到根本原因。

## 3. 修复方案
- `ui/sidebar.js` 单独维护 selectedPath，统一切换整个侧栏的 active；分层与平铺重绘均使用该路径。
- `ui/app.js` 在 Chart / Feat 主动打开入口更新选中项，移除按文档类型分别设置高亮的逻辑。
- `ui/feat.js` 移除异步读取完成后补设高亮的入口，防止覆盖后一次点击；关闭档案时仅清理该档案的选中态。
- 业务流程与文档打开状态不变，不修改流程图。
- 尚未写 README、未提交，等待用户确认修复完成。
